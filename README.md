An interactive, real-time **3D Biological Morphogenesis & Coupled Reaction-Diffusion PDE Engine** built with **Python (WSL Ubuntu telemetry server)**, **Three.js (WebGL)**, and **Custom GLSL Normal-Displacement Shaders**.

🔗 **Live Interactive Web App:** **https://rksupreme5-ux.github.io/turing-morphogenesis-3d/**

## ✨ Key Features
- **Real-Time Coupled Gray-Scott PDE Solver:** Integrates a 128x128 periodic reaction-diffusion lattice using a 9-point isotropic Laplacian stencil at up to 24 sub-steps per frame.
- **56,000-Triangle Deformable 3D Manifold:** Morphs smoothly in mid-air between a Bio-Sphere, Toroidal Bio-Reactor, Hyperbolic Coral Gyroid, and Nautilus Helical Spire.
- **3 Custom GLSL Material Shaders:** Molten Basalt & Solar Gold, Kintsugi Royal Porcelain & 24K Gold, and Iridescent Cyber-Chrome Chitin.
- **Interactive 2D-to-3D Catalyst Brush:** Paint chemical morphogen V directly onto the 2D lattice and watch 3D ridges nucleate and divide on the spinning sculpture.
